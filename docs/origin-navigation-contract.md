# Contrat ergonomique CESAM
Toute création, modification ou validation doit revenir au contexte d'origine : route, filtres, progression et position ; annulation revient à l'élément initial, erreur conserve le formulaire. Dans une file de vérification, succès cible le prochain élément restant, avec confirmation. Ne pas rediriger vers une liste générale par défaut si une origine existe. Les filtres doivent être encodés dans l'URL ou conservés explicitement. Le contrôle des anciens pères est le premier parcours corrigé ; les autres modules nécessitent un audit progressif. Les tests navigateur utilisent une simulation locale, pas le formulaire réel ni ses API.
