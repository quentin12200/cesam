# Phase 2
Le tableau des pères et sa logique historique sont déplacés vers /config/coulisses/peres, sans nouvelle API. Le composant existant est réutilisé. Le Lab utilise les fixtures du prototype espace de travail ; ses raccourcis réels deviennent des aperçus, les actes réels restent accessibles via les menus habituels. Les simulations locales et les deux prototypes restent accessibles.
Limite : le layout global et ses fournisseurs restent ceux de CESAM, et l'utilisateur authentifié peut quitter le Lab. Ceci ne constitue pas encore un environnement de sécurité isolé pour un agent autonome. Ne pas autoriser un agent à utiliser cette session réelle. Le futur environnement dédié doit isoler le serveur, la base et les services externes. Les tests source ne remplacent pas les tests de navigation.
